#### コミュニティAIの直し（2026-11-07 に公開。アーティファクトの版 1794018074-f583）

- M のID：#事例ID と #note-… の両方で S・F・M を受け取る（同じ日に Cowork 側でも同じ直しを公開していた）。
- 型：公開事例306件から27個に作り直した（多企業の型 G023〜G027、社内の型 G021〜G022 を新設。多企業に移った F47 をファン・顧客の型から外し、公開データから消えた F06・F38・S09・S67 も外した）。型の元データのシート「【コミュニティAI】事例から見えた型」にも書いた（黒田さんの判断）。以後は図鑑の公開事例が前回より2割増えるたび（次は367件を超えたとき）に作り直す。
- 役に立ったかの記録：アーティファクトの db は、公開リンクで開いた外部の閲覧者（view）には rules を変えても書き込めない。黒田さんの判断で、図鑑と同じ GoatCounter に community-ai/feedback/useful（not-useful）/段階/種類 のイベントとして数える。アーティファクトの通信の制限で届かないときは、ボタンを出さない（favicon の読み込みで確かめる）。相談の文章は送らない。
- 検索モード（ログインしていない人）：返答の下に、相談から推した種別・目的・段階で絞り込んだ図鑑の一覧へのボタンと、ログインすると何ができるかの1文。種別が分からないときは目的を使わない。
- 本文 15px → 16px。注記の監修者のリンクを Linktree にし、相談相手（壁打ち・伴走）を引き受けていることと、運営者に届くのはボタンの回数と相談の分類だけだと書いた。「この図鑑について」のアクセス解析の説明にも1文を足した。
